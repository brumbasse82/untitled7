Gruppe: Lucas, Kevin, Anwar, Najib

Vi har gemt usernames og password i arrays. Main kalder loginForsøg, programmet starter, og man har 3 forsøg. While loopet kører mens forsøg > 0. Vi får brugernavn og password ved hjælp af scanner og søger efter brugernavnet i arrayet. Programmet tjekker om brugernavnet findes og om passwordet matcher. Hvis loginnet er forkert, trækkes der et forsøg fra, og bruger man alle 3 forsøg, bliver kontoen låst.
